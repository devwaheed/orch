# Sessions

A session is an agent's saved conversation. In **Sessions**, you can filter by **All**, **Resumable**, or **Live**, then inspect its transcript, worktree, run, and activity.

Resume options are:

- **Continue this session**: use the same account. If it is limited, wait for its reset.
- **Hand off to another account**: continue in the same worktree with another account.
- **Hand off to another agent**: continue in the same worktree with another agent.
- **Fork into a new worktree**: start a new session from the current worktree state on a new branch.

Options without an available target are disabled with the reason. A live session offers **Open in workspace**. Ended sessions and their transcripts are kept for 90 days; worktrees are not deleted automatically.
