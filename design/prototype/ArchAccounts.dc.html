The orchestrator asked for a tester, and this job allows Codex for that role.
Reads live usage for every Codex account. Signed-out, switched-off and limited accounts never qualify.
Primary first: use the primary until it nears its limit.
Most headroom: pick the one with the most left. A per-account cap limits parallel runs.
A run stays on one account for its whole session.
Each profile folder has its own login, settings, skills and session history. orch never sees passwords: logins happen in the CLI itself.
Usage events from the run keep the Quota service up to date.
Same account later: continue the exact session after the reset.
Another account or agent: hand off — a new session in the same worktree, primed with a summary.

Checked against vendor docs and existing multi-account tools. orch doctor re-tests this on your machine with two throwaway profiles per agent.
Antigravity: on macOS and Windows its login sits in one shared system-keyring entry, so orch allows one account there and never swaps logins on its own. OpenCode: on Windows it may store its login outside XDG_DATA_HOME, so orch tests before allowing a second account.
